# Dos corazones · Nuestro álbum

Primera versión del álbum digital para celebrar tres años juntos.

## Abrir en tu ordenador

En PowerShell, entra en esta carpeta y ejecuta:

```powershell
npm.cmd run dev
```

Después abre http://localhost:3000 en el navegador.
